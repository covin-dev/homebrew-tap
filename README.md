# Covin Homebrew tap

Covin Local: an on-device guard that checks what your coding agents do against your task.

```sh
brew install covin-dev/tap/covin
covin setup
```

`covin setup` finds your coding agents and asks before changing anything.
Before `brew uninstall covin`, run `covin uninstall` to restore your agents' configs.

Other ways to install, and the release checksums: https://covin.dev/local
